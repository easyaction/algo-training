### 문제 이해
수열 A len(A) <= 1000
가장 긴 증가하는 부분수열?
	부분 수열? 수열에서 일부 숫자만 선택해서 만드는 수열
	순서 그대로 유지해야함
	A = {**10**, **20**, 10, **30**, 20, **50**} => 4
	A = {10, 50, **10**, **15**, **20**, **50**} => 4
	i번째까지의 최장길이 수열에서 다음 숫자를 추가할수 있을지 없을지 판단 후 추가

### 추상화
브루트포스로 계산
1번째부터 i번째까지 순회하면서 마지막 숫자보다 더 큰 숫자 나오면 count 증가하는 식으로 셀수 있음 -> 셀수 없음
	N * (N-1) / 2 = O(N^2) 풀이 가능하지 않을까?
	1 6 2 5 -> 6을 스킵하고 1,2,5를 선택해야 최장길이

DP?
i번째 원소가 나타났을때 이 원소가 최장 길이 수열에 추가 될 수 있는지
-> i번째가 마지막일때, i보다 더 작은 (최장 길이 수열이 될수 있는 원소 j)를 찾자
	arr[j] < arr[i]인 j 중 가장 큰 dp[j]를 갖는 값을 찾아서 그 시점에서의 최장길이를 더해주면 됨
dp[i] = dp[j] + 1 where arr[j] < arr[i]
O(N^2) 풀이
### 계획


### 코드
```python
import sys

input = sys.stdin.readline


def solve(arr: list[int], N: int):
    dp = [0] * N
    for i in range(N):
	    arr_i = arr[i]
        best = 0
        for j in range(i):
            if arr[j] < arr_i and dp[j] > best:
                best = dp[j]
	    dp[i] = best + 1
    print(max(dp))


if __name__ == "__main__":
    N = int(input())
    arr = list(map(int, input().split()))
    solve(arr, N)

```
