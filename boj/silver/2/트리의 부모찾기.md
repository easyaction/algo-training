### 문제 이해
루트 없는 트리가 주어짐
간선을 이루는 두 노드를 알려줌
트리의 루트가 1이라고 할때, 각 노드의 부모 노드를 출력하기

### 추상화
그래프 탐색 문제?
주어진 간선 정보로 그래프를 만들고, 1부터 이웃 노드를 탐색. 이전 노드가 루트노드.

### 계획
DFS로 구현
stack을 이용한 dfs 구현
그래프 초기화
	길이 N의 리스트를 선언하고, 간선 정보를 얻을때마다 해당 인덱스에 노드 추가
	방향이 없기때문에 양방향 모두 넣어주자
	visited를 확인하여 미방문한 노드만 방문
		루트 노드를 기록하는 root 배열을 이용하여 체크하자.
1부터 dfs
	deque에 1 넣고 stack이 빌때까지 반복
	해당 인덱스에 있는 그래프의 인접 노드 인덱스들을 가져와서
		인접 노드를 방문한 적이 없으면(root 노드가 기록되어있지 않으면) stack에 append
		현재 노드를 root 노드로 기록
root node를 순서대로 출력
### 코드
```python
import sys
from collections import deque

input = sys.stdin.readline


def solve(N: int):
    # init graph
    graph = [[] for _ in range(N + 1)]
    for _ in range(N - 1):
        u, v = map(int, input().split())
        graph[u].append(v)
        graph[v].append(u)
    root_nodes = [-1 for _ in range(N + 1)]
    # dfs with stack
    root_nodes[1] = 1
    stack = deque([1])
    while stack:
        cur = stack.pop()
        for nxt in graph[cur]:
            if root_nodes[nxt] == -1:
                root_nodes[nxt] = cur
                stack.append(nxt)
    for i in root_nodes[2:]:
        print(i)


if __name__ == "__main__":
    N = int(input())
    solve(N)

```

### 회고
root node 1에 대한 방문처리 누락
	1에 연결된 노드를 방문했을때 다시 1을 방문하면서 1의 자식노드가 1의 루트노드로 기록됨
	이 문제에서는 2번 노드부터 출력해서 무시되지만, 불필요한 방문을 막기위해 초기화 필요
stack은 그냥 list로 하자.
	deque를 굳이 쓸필요 없음.
