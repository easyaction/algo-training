### 문제 이해
자연수 N개와 자연수 M 주어짐
N개중 M개 고른 수열
같은수 여러번 골라도 됨
수열은 비내림차순이어야함.(오름차순?)
### 추상화
dfs + 백트래킹 + 중복처리?
그런데 중복처리를 단순하게 해시맵으로 하지말고,
dfs 하면서 다음 스텝으로 넘어갈때 선택할 숫자의 범위를 줄여나가면 자연스럽게 중복이 제거될 수 있을 듯 하다.

### 계획
n, m 입력 받기
n들 입력 받으면서 중복 제거 및 정렬
수열 배열 선언
N개의 숫자 입력받기
중복 제거 후 정렬
	입력받은 배열 돌면서 dict에 넣고 keys()로 출력
	갯수가 최대 8개밖에 안되니 이렇게 해도 괜찮을듯
dfs 구현
	이전 depth의 idx부터 끝까지 포룹돌면서
	결과 array가 m과 같으면 출력
	그렇지 않으면
		숫자를 추가하고
		dfs 스텝 증가하면서 재귀호출
		숫자 제거
### 코드
```python
import sys
input = sys.stdin.readline

def solve(N:int, M:int):
    input_dict = {}
    for i in input().split():
        input_dict[i] = True
    inputs = sorted(list(map(int, input_dict.keys())))

    seq = []
    def dfs(start:int):
        if len(seq) == M:
            print(" ".join(map(str, seq)))
            return
        for i in range(start, len(inputs)):
            seq.append(inputs[i])
            dfs(i)
            seq.pop()
    dfs(0)

if __name__ == "__main__":
    N, M = map(int, input().split())
    solve(N, M)
```
개선
```python
import sys
input = sys.stdin.readline

def solve(N:int, M:int):
    inputs = sorted(set(map(int, input().split())))

    seq = [0] * M
    def dfs(start:int, depth:int):
        if depth == M:
            print(" ".join(map(str, seq)))
            return
        for i in range(start, len(inputs)):
            seq[depth] = inputs[i]
            dfs(i, depth+1)
    dfs(0, 0)

if __name__ == "__main__":
    N, M = map(int, input().split())
    solve(N, M)

```

계획을 최대한 상세하게 적어봤는데, 이게 더 적절하다.

		직접 idx 접근하여 값을 설정
		이를 위하여 depth 파라미터 추가
	dict 대신 set 이용
		이게 더 직관적이다.
