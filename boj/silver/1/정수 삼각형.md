### 문제 이해
정수 삼각형이 있음
맨 위층 숫자부터 시작해서 선택한 수 까지 내려오면서 고른 숫자의 합이 최대가 되는 경로 선택하기
삼각형의 크기 n <= 500
### 추상화
목표로 하는 숫자부터 거꾸로 위로 올라가면서 그래프 탐색?(BFS?)
하지만 그냥 순회하면 경우의 수가 너무 많아 제한시간 내에 구할 수 없음
DP로 특정 depth에서의 최대 합을 계산하면 됨
dp(i,j) = cost(i,j) + max(dp(i-1)(j-1), dp(i-1)(j))
다 구한 후 마지막 depth 구할때 목표한 숫자에 대해서 마지막으로 dp 구하면서 최대값 반환

### 계획
삼각형 초기화
	2차원 배열로 초기화
	n만큼 순회하면서 append
dp = [ [0 for _ in range(i+1) ] for i in range(n)]
dp(0)(0) = arr(0)(0) 초기화
for i in range(1, n):
	for j in range(i+1):
		if i == n-1 and arr(i)(j) != target:
			continue
		left = 0
		if j > 0:
			left = dp(i-1)(j-1)
		right = 0
		if j < i:
			right = dp(i-1)(j)
		dp(i)(j) = arr(i)(j) + left if left > right else right
		
### 코드
```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    # init int triangle
    arr = []
    for _ in range(N):
        arr.append(list(map(int,input().split())))

    dp = [ [0 for _ in range(i+1) ] for i in range(N)]
    for i in range(N):
        for j in range(i+1):
            left = 0
            if j > 0:
                left = dp[i-1][j-1]
            right = 0
            if j < i:
                right = dp[i-1][j]
            sum_ij = arr[i][j]
            if left > right:
                sum_ij += left
            else:
                sum_ij += right
            dp[i][j] = sum_ij
    print(max(dp[N-1]))
        

if __name__ == "__main__":
    solve()

```
개선
```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    # init int triangle
    arr = []
    for _ in range(N):
        arr.append(list(map(int,input().split())))

    for i in range(N):
        for j in range(i+1):
            left = arr[i-1][j-1] if j > 0 else 0
            right = arr[i-1][j] if j < i else 0
            arr[i][j] += max(left, right)
    print(max(arr[N-1]))
        

if __name__ == "__main__":
    solve()

```
