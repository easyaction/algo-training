### 문제 이해
x1, y1부터 x2, y2까지의 합을 구하기
NxN 숫자


### 추상화
브루트 포스로 구현한다고 하면..
	조건에 맞는 좌표 x1 <= x <=x2 , y1 <= y <= y2
	전부 더하기
	O(N^2 * M) => 10^9 이 되므로 시간 초과
부분합을 이용하여 중복 연산을 줄려 O(NM) 내지는 O(M)으로 만들어야 통과가 가능하겠다.
합산을 O(1)로 줄일 수 있을까?
O(N)으로는 할 수 있겠다.
	행이나 열으로만 부분합을 구함
	x1 -> x2까지 순회하면서
	(x)(y2)-(x)(y1-1) 을 구하고 각각을 더함
	O(NM) = 10^8 ... 간당간당함
O(1)로 줄여보자
	전체에 대해 부분합 구하기
	네개의 합으로 구하기
	prefix(i)(j) = prefix(i-1)(j) + prefix(i)(j-1) - prefix(i-1)(j-1)
	결과 = prefix(x2)(y2) - prefix(x1-1)(y2) - prefix(x2)(y1-1) + prefix(x1)(y1) 
### 계획


### 코드
1d prefix sum - O(NM)
```python
import sys
input = sys.stdin.readline


def solve():
    N, M = map(int,input().split())
    arr = []
    for _ in range(N):
        row = list(map(int, input().split()))
        s = 0
        for i, n in enumerate(row):
            s += n
            row[i] = s
        arr.append(row)
    for _ in range(M):
        x1, y1, x2, y2 = map(int, input().split())
        x1 -= 1
        x2 -= 1
        y1 -= 1
        y2 -= 1

        result = 0
        for x in range(x1, x2+1):
            result += arr[x][y2]
            if y1 > 0:
                result -= arr[x][y1-1]
        print(result) 
            

if __name__ == "__main__":
    solve()
```
2d prefix sum - O(M)
```python
import sys
input = sys.stdin.readline


def solve():
    N, M = map(int,input().split())
    arr = []
    for _ in range(N):
        arr.append(list(map(int, input().split())))
    prefix = [[0 for _ in range(N)] for _ in range(N)]
        
    for i in range(N):
        for j in range(N):
            prefix[i][j] = arr[i][j]
            if i != 0:
                prefix[i][j] += prefix[i-1][j]
            if j != 0:
                prefix[i][j] += prefix[i][j-1]
            if i != 0 and j != 0:
                prefix[i][j] -= prefix[i-1][j-1]
    for _ in range(M):
        x1, y1, x2, y2 = map(int, input().split())
        x1 -= 1
        x2 -= 1
        y1 -= 1
        y2 -= 1

        result = prefix[x2][y2]
        if x1 > 0:
            result -= prefix[x1-1][y2]
        if y1 > 0:
            result -= prefix[x2][y1-1]
        if x1 > 0 and y1 >0:
            result += prefix[x1-1][y1-1]
        print(result) 
            

if __name__ == "__main__":
    solve()
```
개선
```python

import sys
input = sys.stdin.readline


def solve():
    N, M = map(int,input().split())
    arr = []
    for _ in range(N):
        arr.append(list(map(int, input().split())))
    prefix = [[0] * (N+1) for _ in range(N+1)]
    for i in range(1, N+1):
        for j in range(1, N+1):
            prefix[i][j] = arr[i-1][j-1] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]
    for _ in range(M):
        x1, y1, x2, y2 = map(int, input().split())
        result = prefix[x2][y2] - prefix[x1-1][y2] - prefix[x2][y1-1] + prefix[x1-1][y1-1]
        print(result) 
            

if __name__ == "__main__":
    solve()
```
