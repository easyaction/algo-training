### 문제 이해
자연수 A를 B번 곱하고 이를 C로 나눈 나머지를 구하라
a,b,c <= 2,147,483,647
### 추상화
단순 구현으로 하면?
오버플로우가 안나게 하는게 포인트
B가 너무 커서 그냥도 오래걸림
계산이 중복되는 부분을 최적화 해야함
같은 수를 곱하기 때문에, 계산 값을 합칠 수 있음
B가 짝수면 2의 제곱 구하고 이를 곱해주면 됨
1 2 4 8 16 32 ...
B가 2의 제곱수 어디에 속하는지 찾고
19라고 하면 16 * 2 * 1
이걸 어떻게 구현할 것인가?
계산한걸 캐싱하면서해보자.

### 코드
```python
import sys
input = sys.stdin.readline

def solve():
    a,b,c = map(int, input().split())
    dp = {}
    nth_power = a
    dp[1] = a
    n = 2
    while n <= b:
        dp[n] = nth_power * nth_power % c
        nth_power = dp[n]
        n *= 2
    n = n // 2
    ans = 1
    while b > 0 and n > 0:
        if n <= b:
            ans = ans * dp[n] % c
            b -= n
        n = n // 2
    print(ans % c)

if __name__ == "__main__":
    solve()

```
재귀 호출
```python
import sys
input = sys.stdin.readline

def power(a, b, c) -> int:
    if b == 0:
        return 1 % c
    half = power(a, b // 2, c)
    if b % 2 == 1:
        return (half * half % c) * a % c
    else:
        return half * half % c

def solve():
    a,b,c = map(int, input().split())
    print(power(a,b,c))

if __name__ == "__main__":
    solve()

```
반복문
```python
import sys
input = sys.stdin.readline

def power(a, b, c) -> int:
    ans = 1
    a = a % c
    while b > 0:
        if b % 2 == 1:
            ans = ans * a % c
        a = a * a % c
        b = b // 2
    return ans % c

def solve():
    a,b,c = map(int, input().split())
    print(power(a,b,c))

if __name__ == "__main__":
    solve()

```
