### 문제 이해
숫자 2행 2n개
숫자 하나 선택하면 인접한 숫자는 선택할 수 없음
선택한 숫자의 합의 최대값
N <= 10 ^ 5

### 추상화
DP 문제
i번째 열을 선택할때, 이전 열의 위/아래 최대값에 맞춰 더하면 됨
보통 지그재그로 선택하게됨
0 a b c
1 e f g
c와 g중 선택을 한다하면
c의 경우 - a f c 이거나 e c
g의 경우 - e b g or a g
i번째 열 0번째 행 = arr(0)(i) + max(dp(1)(i-1), dp(1)(i-2))
i번째 열 1번째 행 = arr(1)(i) + max(dp(0)(i-1), dp(0)(i-2))

### 계획
입력 받기
	T
	N
	위쪽 입력
	아래쪽 입력
풀이 함수(N, 배열)
dp 초기화
dp 채워넣기
print(max(dp(0)(N), dp(1)(N)))

### 코드
```python
import sys
input = sys.stdin.readline


def solve():
    N = int(input())

    arr = [[0,0] for _ in range(N)]
    for i, n in enumerate(map(int, input().split())):
        arr[i][0] = n
    for i, n in enumerate(map(int, input().split())):
        arr[i][1] = n

    if N == 1:
        return max(arr[0])

    # dp
    arr[1][0] += arr[0][1]
    arr[1][1] += arr[0][0]
    for i in range(2, N):
        arr[i][0] += max(arr[i-1][1], arr[i-2][1]) 
        arr[i][1] += max(arr[i-1][0], arr[i-2][0]) 
    return max(arr[N-1])

if __name__ == "__main__":
    T = int(input())
    for _ in range(T):
        print(solve())
```
행렬 배열 바꿈
```python
import sys
input = sys.stdin.readline


def solve():
    N = int(input())

    arr = []
    arr.append(list(map(int, input().split())))
    arr.append(list(map(int, input().split())))
    
    if N == 1:
        return max(arr[0][0], arr[1][0])

    # dp
    arr[0][1] += arr[1][0]
    arr[1][1] += arr[0][0]
    for i in range(2, N):
        arr[0][i] += max(arr[1][i-1], arr[1][i-2]) 
        arr[1][i] += max(arr[0][i-1], arr[0][i-2]) 
    return max(arr[0][N-1], arr[1][N-1])

if __name__ == "__main__":
    T = int(input())
    for _ in range(T):
        print(solve())
```
