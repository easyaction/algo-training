### 문제 이해
우선순위가 가장 높은 데이터 혹은 가장 낮은 데이터를 삭제하는 이중 우선순위 큐
삽입/삭제
연산 완료 된 후 q에 남아있는 최소값과 최대값 구하기
입력
T - 테스트 케이스 수
Q - 명령 수 k (<=10 ^ 6)
D 1 -> 최대값 삭제
D -1 -> 최솟값 삭제
I n -> n을 삽입
비어있으면 EMPTY 출력
### 추상화
최대 힙과 최소 힙을 어떻게 동시에 관리할것인지?
각각의 최대 힙 / 최소 힙을 선언하고, 최대값을 제거할때에는 최대 힙을 최소값을 제거할때에는 최소 힙을 이용
카운터를 별도로 두고 최대값 삭제 횟수와 최솟값 삭제 횟수가 삽입 횟수를 넘는지 확인
넘으면 EMPTY 출력


### 계획
min/max heap을 선언
I n이 나오면 min/max 힙 각각에 삽입
	카운터 증가
D 1이 나오면 max 힙 pop
D -1이 나오면 min 힙 pop
	각각 카운터 감소
counter < 0 라면 empty 출력
그게 아니라면 min[0] max[0] 출력

### 코드
```python
import sys
import heapq
input = sys.stdin.readline


def solve():
    min_heap, max_heap = [], []
    Q = int(input())
    alive = [False] * (Q)
    for idx in range(Q):
        cmd, n = input().split()
        if cmd == "I":
            num = int(n)
            heapq.heappush(min_heap, (num, idx))
            heapq.heappush(max_heap, (-num, idx))
            alive[idx] = True
        elif cmd == "D":
            if n == "1":
                while max_heap and not alive[max_heap[0][1]]:
                    heapq.heappop(max_heap)
                if max_heap:
                    _, idx = heapq.heappop(max_heap)
                    alive[idx] = False
            else:
                while min_heap and not alive[min_heap[0][1]]:
                    heapq.heappop(min_heap)
                if min_heap:
                    _, idx = heapq.heappop(min_heap)
                    alive[idx] = False
    while min_heap and not alive[min_heap[0][1]]:
        heapq.heappop(min_heap)
    while max_heap and not alive[max_heap[0][1]]:
        heapq.heappop(max_heap)
    if len(min_heap) == 0 and len(max_heap) == 0:
        print("EMPTY")
    else:
        print(-max_heap[0][0], min_heap[0][0])

if __name__ == "__main__":
    T = int(input())
    for _ in range(T):
        solve()

```
