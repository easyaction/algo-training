### 문제 이해
테트로미노 하나를 놔서 놓은 위치의 숫자의 합이 최대일때의 숫자를 반환
테트로미노는 회전/ 대칭 가능

### 추상화
브루트포스로 전부 숫자를 계산
250000(500x500) * (2 + 1 + 8 + 4 + 4) = 4750000
5 * 10^6
테트로미노가 회전/대칭인 경우도 경우의 수로 넣어서 (i,j)에서의 계산 가능 여부와 계산 값을 구하기
### 계획
테트로미노의 탐색 각각을 구현
type 1 - [ (0, 0), (0,1), (0,2), (0,3) ], [(0,0), (1,0), (2,0), (3,0)]
type 2 - [(0,0), (0,1), (1,0), (1,1)]
type 3 - [(0,0), (0,1), (0,2), (1,2)], [(0,0), (0,1), (0,2), (-1,2)], [(0,0), (1,0), (2,0), (2,1)],  [(0,0), (1,0), (2,0), (2,-1)]
type 4 - [(0,0), (0,1), (1,1), (1,2)], [(0,0), (0,1), (-1,1), (-1,2)], [(0,0), (1,0), (1,1), (2,1)],  [(0,0), (1,0), (1,-1), (2,-1)]
type 5 - [(0,0), (0,1), (0,2), (1,1)], [(0,0), (0,1), (0,2), (1,-1)], [(0,0), (1,0), (2,0), (-1,1)],  [(0,0), (1,0), (2,0), (1,1)]
변수 접근을 최소화 하려면 prefix sum같은걸 이용할 수 있겠다.
	앞단계에서 저장했던 값을 재활용
	그런데 이렇게까지 할필요는 없을듯 함
NxM에 대하여 i,j를 순회하며 위 좌표의 값을 가져와서 합산
	이때 범위 넘어서면 중단

개선
```python
import sys
input = sys.stdin.readline

tetrominos = [
    [(0, 0), (0,1), (0,2), (0,3) ], [(0,0), (1,0), (2,0), (3,0)], # type 1
    [(0,0), (0,1), (1,0), (1,1)], # type 2
    [(0,0), (0,1), (0,2), (1,2)], [(0,0), (0,1), (0,2), (-1,2)], [(0,0), (1,0), (2,0), (2,1)],  [(0,0), (1,0), (2,0), (2,-1)],
    [(0,0), (0,1), (0,2), (1,0)], [(0,0), (0,1), (0,2), (-1,0)], [(0,0), (1,0), (2,0), (0,1)],  [(0,0), (1,0), (2,0), (0,-1)], # type 3
    [(0,0), (0,1), (1,1), (1,2)], [(0,0), (0,1), (-1,1), (-1,2)], [(0,0), (1,0), (1,1), (2,1)],  [(0,0), (1,0), (1,-1), (2,-1)], # type 4
    [(0,0), (0,1), (0,2), (1,1)], [(0,0), (0,1), (0,2), (-1,1)], [(0,0), (1,0), (2,0), (1,-1)],  [(0,0), (1,0), (2,0), (1,1)], #type 5
]

def test_tetrominos():
    for t in tetrominos:
        arr = [[0 for _ in range(5)] for _ in range(5)]
        for dx, dy in t:
            nx, ny = 1+dx, 1+dy
            arr[nx][ny] = 1
        print("type : ",t)
        for x in range(5):
            print(arr[x])

def solve(arr:list[list[int]], N:int, M:int) -> int:
	# min/max preprocessing
    shapes = []
    for t in tetrominos:
        min_dx = min(dx for dx, dy in t)
        max_dx = max(dx for dx, dy in t)
        min_dy = min(dy for dx, dy in t)
        max_dy = max(dy for dx, dy in t)
        shapes.append((t, min_dx, max_dx, min_dy, max_dy))
    
    grid = arr
    best = 0
    for i in range(N):
        for j in range(M):
            for t, min_dx, max_dx, min_dy, max_dy in shapes:
                if i + min_dx < 0 or i + max_dx >= N:
                    continue
                if j + min_dy < 0 or j + max_dy >= M:
                    continue
                s = 0
                for dx, dy in t:
                    s += grid[i+dx][j+dy]
                if s > best:
                    best = s
    return best


if __name__ == "__main__":
    N,M = map(int, input().split())
    arr = []
    for _ in range(N):
        arr.append(list(map(int, input().split())))
    print(solve(arr, N, M))


```
### 회고
처음에 nx, ny 범위 체크할때 filter를 사용했는데, 불필요하게 복잡하고 성능도 좋지 않음
	직관적인 for loop을 사용하자
type 3 모양 케이스 하나를 빼먹어서 처음에 틀렸음
	모든 경우의 수를 다 고려했는지 꼭 찾아보자.
불필요한 경계값 확인을 제거하면 더 빨라질 수 있음
	 dx, dy에 대하여 min/max를 미리 구해두고, i,j에 대해서 범위를 초과하는지 먼저 검사하면 매번 다 안더해도 됨.
