### 문제 이해
줄을 내려가면서 최소/최대 점수 구하기
첫번째 칸에서는 1, 2번 두번째는 1,2,3 3번쨰는 2,3만 가기 가능

### 추상화
DP
각 위치에서 얻을 수 있는 최대/ 최소 점수를 DP에 저장
dp(i)(1) = min/max(dp(i-1)(1), dp(i-1)(2))
dp(i)(2) = min/max(dp(i-1)(1), dp(i-1)(2), dp(i-1)(3))
dp(i)(3) = min/max(dp(i-1)(2), dp(i-1)(3))
그리고 전 스텝의 값만 필요하기 때문에 변수로만 선언하면 됨
### 계획
N 입력
배열 초기화
순회하면서 전 스텝의 min/max값을 이용하여 계산
마지막 스텝에서 min/max 출력
### 코드
```python
import sys

input = sys.stdin.readline


def solve():
    N = int(input())

    # dp
    dp = [[0, 0, 0], [0, 0, 0]]
    for i in range(N):
        x, y, z = map(int, input().split())
        nxt = [[x, y, z], [x, y, z]]
        if i != 0:
            nxt[0][0] += min(dp[0][:2])
            nxt[0][1] += min(dp[0])
            nxt[0][2] += min(dp[0][1:])

            nxt[1][0] += max(dp[1][:2])
            nxt[1][1] += max(dp[1])
            nxt[1][2] += max(dp[1][1:])
        dp = nxt
    print(max(dp[1]), min(dp[0]))


if __name__ == "__main__":
    solve()
```

개선
```python
import sys

input = sys.stdin.readline


def solve():
    N = int(input())

    # dp
    max_sum = []
    min_sum = []
    for i in range(N):
        x, y, z = map(int, input().split())
        if i == 0:
            max_sum = [x,y,z]
            min_sum = [x,y,z]
        else:
            max_sum = [x + max(max_sum[:2]), y + max(max_sum), z + max(max_sum[1:])]
            min_sum = [x + min(min_sum[:2]), y + min(min_sum), z + min(min_sum[1:])]
    print(max(max_sum), min(min_sum))


if __name__ == "__main__":
    solve()

```
