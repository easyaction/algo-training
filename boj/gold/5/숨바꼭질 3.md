### 문제 이해
N에서 K로 이동하는데, 1초 후 x-1 혹은 x+1 / 0초 후 2X
최소시간 구하기
### 추상화
DP
뭘 구해야하나? N에서 K 까지 가는데 걸리는 최소 시간
변하는 변수? 시간, 위치
이를 이용하여 상태를 나타낼 수 있는지?
	해당 위치까지 가는데 걸리는 최소시간?
	dp[X] = min(dp[x-1]+1, dp[x+1]-1, dp[2^n * x])
포인트는 2배수는 시간이 추가로 소요되지 않는다는 점
어떻게 탐험할까?
bfs?
### 계획
N으로부터 bfs로 +1, -1, 2에 대해서 탐색한다. 
	2배수 설정시에는 2k 미만에 대해서만 설정
탐색시 k에 도달하면 종료
### 코드
```python
import sys

input = sys.stdin.readline
from collections import deque


def solve():
    N, K = map(int,input().split())
    if N == K:
        return 0
    LIMIT = max(N, 2*K)
    min_seconds = [-1] * LIMIT
    min_seconds[N] = 0
    q = deque([(N)])
    dirs = (-1, +1)
    while q:
        cur = q.popleft()
        if cur == K:
            return min_seconds[cur]
        if cur < K:
            double = 2 * cur
            if double <= LIMIT and min_seconds[double] == -1:
                min_seconds[double] = min_seconds[cur]
                q.appendleft((double))
        for dir in dirs:
            nxt = cur + dir
            if 0 <= nxt <= LIMIT and min_seconds[nxt] == -1:
                min_seconds[nxt] = min_seconds[cur] + 1
                q.append((nxt))
    return -1

if __name__ == "__main__":
    print(solve())

```
