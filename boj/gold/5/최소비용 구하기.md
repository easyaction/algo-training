### 문제 이해
N개 노드 M개의 간선
a -> b 가는데 드는 비용 최소화
최소 비용 출력

### 추상화
다익스트라?
bfs를 하면서 노드를 탐색
다음 노드 비용과 현재 저장된 비용을 비교해서 더 낮은것을 유지
우선순위 큐 써야함
### 계획
그래프 구조
	k: 출발 v: (도착, 비용) 배열
비용 배열(dp)
	길이 N, 최소 비용
그래프 초기화
	도시 수 N
	그래프 수 M
	M번 반복
		출발, 도착, 비용
A,B 입력
A부터 bfs
	A 조회
	nxt마다
		dp(nxt) 가 dp(cur) + cost 보다 크면 업데이트 아니면 유지
dp(cost)


### 코드
```python
import sys
input = sys.stdin.readline
import heapq


def solve():
    N  = int(input())
    M = int(input())
    graph = [[] for _ in range(N+1)]
    dp = [float('inf') for _ in range(N+1)]
    for _ in range(M):
        src, dest, cost = map(int, input().split())
        graph[src].append((dest, cost))
    A, B = map(int, input().split())
    dp[A] = 0
    q = [(0,A)]
    while q:
        cost, cur = heapq.heappop(q)
        if dp[cur] < cost:
            continue
        for nxt, cost in graph[cur]:
            from_cur = dp[cur] + cost
            if dp[nxt] > from_cur:
                dp[nxt] = from_cur
                heapq.heappush(q,(cost, nxt))
    print(dp[B])

if __name__ == "__main__":
    solve()
```
