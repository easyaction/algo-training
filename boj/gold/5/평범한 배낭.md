### 문제 이해
n개 물건
w무게 v 가치
최대 k 무게
가치 최대값은?

### 추상화
단순히 최대 가치를 고르는 선택만 하는건 아님
DP
dp 배열에 i번째 물건과 남은 무게 w로 초기화
그 물건을 선택했을때와 아닐때 최대 값을 dp에 저장
### 계획
### 코드
```python
import sys

input = sys.stdin.readline


def solve():
    N, K = map(int,input().split())
    dp = [[ 0 for _ in range(K+1) ] for _ in range(N+1)]
    for i in range(N):
        w, v = map(int,input().split())
        for j in range(K+1):
            if j >= w:
                dp[i+1][j] = max(dp[i][j], dp[i][j-w] + v)
            else:
                dp[i+1][j] = dp[i][j]
    print(max(dp[N]))


if __name__ == "__main__":
    solve()

```
최적화
```python
import sys

input = sys.stdin.readline


def solve():
    N, K = map(int,input().split())
    dp = [ 0 for _ in range(K+1) ]
    for i in range(N):
        w, v = map(int,input().split())
        for j in range(K, w-1, -1):
            dp[j] = max(dp[j], dp[j-w] + v)
    print(dp[K])

if __name__ == "__main__":
    solve()

```
